# Replica-interference simulation

This repository simulates replica-interference protocols for estimating traces of powers of a density matrix, such as $\mathrm{Tr}(\rho^m)$, using folded-unitary circuits and Richardson/R-ZNE mitigation.

The project contains two parallel implementations:

- `replica_sim/`: a cleaned baseline implementation using effective block-noise models.
- `replica_exact/`: a paper-style exact circuit implementation where noise is applied locally inside the folded replica circuit.

Both implementations share the same high-level idea: prepare the ancilla + replicated system state, apply the controlled cyclic permutation, fold the unitary as $U(U^\dagger U)^c$, then measure the ancilla expectation value that recovers the target replica quantity.

## Project purpose

The core observable is the exact replica value

$$
\mathrm{Tr}(\rho^m),
$$

which is estimated from the folded interferometric signal. The code supports single-qubit noise channels such as:

- `phase_flip` / `dephasing`
- `depolarizing`
- `amplitude_damping`

and provides two-point extrapolation estimators:

- `rzne_two_point(R1, R3)`
- `richardson_two_point(R1, R3)`

## Repository layout

- `replica_sim/`
  - `__init__.py`: public package API
  - `protocol.py`: `ReplicaExperiment` and folded circuit execution
  - `noise.py`: effective block-noise channels applied to selected qubits
  - `estimators.py`: R-ZNE and Richardson estimators
  - `state.py`: density-matrix validation and exact trace-power utilities
  - `permutation.py`: cyclic and controlled permutation operators
  - `config.py`: default simulation settings
- `replica_exact/`
  - `circuit.py`: `ReplicaPaperExperiment` for the exact paper-style circuit
  - `noise.py`: gate-local noise application to the folded circuit
  - `analysis.py`: log-linear diagnostics and error summaries
  - `plotting.py`: plotting utilities for diagnostic figures
- `experiments/`
  - `run_single.py`: minimal deterministic smoke check
  - `run_effective_noise.py`: baseline effective block-noise benchmark sweep
  - `run_paper_exact.py`: exact paper-style simulation and plot generation
- `results/`
  - `data/`: saved numerical outputs from experiments
  - `figures/`: generated figures
- `tests/`
  - `test_core.py`: core sanity checks
- `legacy/`
  - `replica_qutip_rough.py`: rough historical prototype retained for provenance only

## Quick start

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the simplest smoke test:

```bash
python experiments/run_single.py
```

Run the cleaned effective-noise benchmark suite:

```bash
python experiments/run_effective_noise.py
```

Run the paper-exact simulation and generate plots:

```bash
python experiments/run_paper_exact.py
```

Run the test suite:

```bash
pytest -q
```

## Minimal Python usage

```python
import qutip as qt
from replica_sim import ReplicaExperiment, rzne_two_point

rho = qt.Qobj([[0.8, 0.2], [0.2, 0.2]])
exp = ReplicaExperiment(rho, m=2)

exact = exp.exact
R1 = exp.run_folded(0, channel="phase_flip", strength=0.02, scope="ancilla")
R3 = exp.run_folded(1, channel="phase_flip", strength=0.02, scope="ancilla")
mitigated = rzne_two_point(R1, R3)

print(exact, R1, R3, mitigated)
```

## Notes on the two simulation modes

- `replica_sim` is the cleaned baseline and intentionally keeps the effective post-block noise model separate from the more detailed gate-local model.
- `replica_exact` is the more faithful paper-style implementation used for generating the harder exact benchmark results and diagnostics.
- `results/` is intended for generated data and plots; these files should be regenerated from the scripts rather than edited by hand.

## References in this repository

This project is structured around folded replica-interference circuits and the associated mitigation analysis used to recover the noiseless quantity from noisy folded measurements. The saved outputs under `results/data` and `results/figures` are generated by the experiment scripts above.
